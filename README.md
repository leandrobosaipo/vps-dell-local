# VPS Dell local

Configuração de acesso e operação do servidor local Dell, preservando o Windows e usando Ubuntu 24.04 em Hyper-V.

Endereço solicitado: `https://painel-dell.codigo5.com.br`. Publicação, proteção e acesso remoto estão em preparação; este arquivo não declara serviço disponível.

O conector Cloudflare e o painel deverão rodar no próprio Dell. O notebook é cliente de administração. Fontes, runbooks sanitizados e manifests ficam neste projeto; segredos e recibos privados permanecem fora do Git. A base compartilhada está em [codigo5-agentes-infra](https://github.com/leandrobosaipo/codigo5-agentes-infra).

GitHub preserva código. Não substitui backup dos volumes, credenciais, dados ou validação de restauração.
